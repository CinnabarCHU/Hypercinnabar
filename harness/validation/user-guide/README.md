## 需要保留的差异

- **日照量/ETP 的补零设置**：手册面板显示 NFFT=2001，图中标注的频率却对应 5×2001 的网格。两种设置都保存。不能把 5 倍补零结果当成面板设置已经复现的证明。
- **ETP 文件的实际配方**：附带数据匹配 `z(E)+0.5z(T)-z(P)`，与文件名一致；同一 La04 数据和样本标准差重算的最大差小于 5e-9。手册正文写成 `E+T-P`。本轮没有替换原示例数据。
- **瓦窑谱的拟合方式**：正文要求 5 倍补零、对数功率拟合；截图显示 NFFT=534、线性功率拟合。主结果按正文，另外保存 5N/linear 与 N/linear 对照。原始核中的 `linlog=1` 是 linear，`linlog=2` 才是 log。
- **其他文字/截图差异**：日照量正文写 June 22，文件名为 day-80；小波最大周期分别出现 1000 和 700 kyr；ETP 演化谱步长分别出现 3.2 和 2 kyr；瓦窑 40 m 窗口被描述成 33.9 m 的 1.5–2 倍。选择依据记录在 manifest 中。
- **年龄模型历史问题**：辅助输出 `agemodelfull` 的端点外推将深度差乘以沉积速率，量纲不对。本例与按控制点线性外推相差最多约 282.24 kyr。手册实际保存并用于 `AgeScale` 的是 `agemodel` 峰值控制点，故该调谐路径不使用有问题的辅助端点。问题单独保留，未在验收时改写科学结果。

## 阅读验收结果

`execution_ok` 要求各角色正常返回且完成状态为 `done`；`criteria_ok` 另外要求手册结果检查通过。两者分开，CI 中因手册描述不符而失败的案例不会被改成通过。

峰位检查保留未经舍入的数值：检查一个未补零 Rayleigh 频率间隔，并单独检查是否可舍入到手册给出的精度。例如 1.82045 m 可舍入为约 1.8 m。低频处一个 Rayleigh 间隔对应较大的周期差，因此这不是对周期精度的保证；完整主峰表保留在 JSON 中。

COCO 的旧函数可能输出经验概率 0。本例的含义是有限次模拟未超过观测统计量；报告另列 `(超越次数+1)/(模拟次数+1)`，不把经验 0 解释为真实概率为零。逐点显著性也不是对整个沉积速率搜索的全局错误率保证。

本轮验收覆盖第 6 章三组案例的导入、预处理、谱分析/演化谱/小波、COCO/eCOCO、滤波和年龄调谐。演化谱及小波主要频带已看图核对，但未做像素相似度评分或穷尽每条科学解释；第 3–5 章全部菜单示例、桌面交互、模型自主规划、节点编辑器和跨 MATLAB 版本位级一致性均不在本轮结论内。

## 重放

`mtm-replay-examples.zip` 是三组主 MTM analyzer 的原生日志和 MAT 引用，作为永久保留的紧凑样例。解压后，在本分支运行 `setup_migration`，将任一 `events.jsonl` 的完整路径交给 `aclog.replay` 即可。每次重放会生成自己的日志。完整 helper/analyzer/plotter 请求、响应和交换记录在对应 Actions artifact 中，受 Actions 保存期限限制；可用仓库中的固定输入和驱动重新生成。

源代码、参数来源、环境及命令详见 [`tests/user_guide`](../../../tests/user_guide/README.md) 和 [`manifest.json`](../../../tests/user_guide/manifest.json)。
