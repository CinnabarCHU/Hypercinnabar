# MATLAB 方法内部实现

从 GUI 回调或脚本中提取、供接口直接调用的函数先集中在普通目录 `code/method/`。`setup_migration` 把这棵目录加入搜索路径。新的 MATLAB 文件与主函数同名，新声明的名称在项目内唯一。单独导出时，GUIDE 版跟随所选接口的函数引用；3.1.1 版沿用其动态调用的整树策略，有 MATLAB 实现后随包带走本目录。原来可独立调用的数值函数留在对应的上游快照，按所选版本直接调用。

提取原代码时用 `%%` 标出照抄区段，注明固定提交、路径和行号。仅在已有函数或代码块无法满足契约时写适配代码。目录可见性与公开接口分开管理，公开的 `helper`、`analyzer`、`plotter` 按操作登记。以后按模块整理此目录时保留函数名与版本化调用记录。[逐项维护归属](../../audit/MODULE_CONSOLIDATION.zh-CN.md)
