# Leg 138 全卷逐页校读版

成品总目录为 `index.html`，可双击打开。每个出版物有独立 HTML、PDF 和逐行位置档。SP 与 PR 各为一册，IR 和 SR 按原分发文件拆分。打开总目录的某章后，可以按来源 PDF 物理页直接跳转。PDF 书签的每组页以一张原页为单位，先读现代排版，再看该页完整见证；遇到已核对的重绘、站卡或校订表会多出若干页。连续阅读原刊请使用章节页首的 Publisher PDF 链接。

## 来源、栏序和精校

- `documents.csv` 登记每册的原 URL、输入与输出 SHA-256、原页数和新版页数。`pages.csv` 记录来源页号、候选印页、现代排版起止页、整张原刊见证位置、分栏参数和低分辨率像素校验。候选印页沿用主编目，原刊页脚可据见证核对。
- `audit/<文献编号>.jsonl.gz` 每个来源页一行。物理行段保留源文字、原块号、行号、分段号、坐标、方向和推定阅读角色。双栏页用左右栏的长行边缘估算栏沟，在通栏正文或标题处重新分区；段间按左栏、右栏阅读。栏沟证据不足时采用原块与纵向坐标。公式、刻度、旋转文字、密集数据等不能可靠判作正文时保留位置档和完整见证。源行末已有的连字符照存。正文选用 DejaVu Serif，标题与图注使用 DejaVu Sans；font_check.json 对实际进入重排的文字逐字符核对 TTF 的 Unicode 映射。字符级的 OCR、斜体、上标和下标需回看原页。本版没有全卷逐字精校。
- 完整原页直接复制进分册 PDF，保留页面尺寸、图表、照片、标尺、原有字形和 OCR 层。每页在低分辨率重绘后与原件逐像素比对。此检查核对复制后的显示；它不能证明 OCR 因此正确。
- 在章节 HTML 的 “Source item locations on this page” 展开对应图表。来源清单 `source_regions.csv` 指向原页图注块、完整页或已校准图面，`regions/` 提供按原坐标裁出的 PNG 及所属整页。候选图注块可能包含邻近文字；图形的实际外框只有在忠实复现原布局并已有独立边界记录时才单列。IR 项目目录中的卷外折页保留其官方容器链接。
- 12 张航前站位卡使用既有精校字段。已整理的印表、重复测量与校读数据保留刊载值，以现代真表格排版。现代 PDF 可按列组和续页拆表，共用 CSV 行号。HTML 提供可滚动的表格，CSV 保留全部字段及出处。各站的数据文件、IR/SR 电子表和版本各自挂接。`resources.csv` 分别标出项目页锚点、仅章级关联及航中引用随盘表的情形。图面读数、代码重绘和原图各保留其身份。
- PR 11 站的速率重绘、图 15 回推读图、SR 第 6 章图 11 与第 27 章图 3 的核验版面以出版社对应页定位。图下的科学解释和缩写均需维持原报告语境。本版收录 PR、IR、SR 和 SP 主体分发文献；独立岩芯图版册、单芯原照及原仪器目录可在档案相应模块查询。

## 重建

合并轻目录和相关来源包，在 Leg138 根目录运行。Python 3.11+，PyMuPDF、ReportLab、Pillow，以及 DejaVu Sans、DejaVu Serif 的 TTF 文件。

```bash
python edition2/build_edition.py . full_edition --workers 4
python edition2/verify_edition.py . full_edition
python edition2/verify_regions.py full_edition
python edition2/check_fonts.py full_edition
python edition2/verify_updates.py . full_edition
python edition2/verify_sr_annex.py . full_edition
python edition2/finish_release.py full_edition edition2
```

磁盘里如保留工程原布局 `integration/core/data`，构建器会自动找到。若字体在其他目录，用 `--fonts /path/to/dejavu` 指定。单册复建使用 `--doc IR.C09`，可重复提供此参数，并选用独立的输出目录。实际出版文件可由分册目录中的输出 SHA-256 核查；不同软件版本产生不同的 PDF 元数据或对象布局时，逐页几何、显示及文字位置核验仍可独立复跑。

## SR 印表附读与综合地层图

SR 的 177 张补充印表按出版物、表号、物理页及续段定位。附读中的 P01、P02 等标记只描述当前页段的位置。HTML 保留候选行栏、字框与原 token；联系不明的跨列标记保留位置范围。独立的竖排表头读数附原页坐标，不自动配对样品或物种。样品归属未定的可见标记独立计数。只对人工确认的具名值或核过表区几何的候选读数增加 PDF 附页，主体来源页及率图的原有页号沿用。

PR 综合地层图的 PDF、独立矢量层和出处表可从原来源页所在的网页打开。66 个物性面板使用不同的船上发布数列，解释与单位图层保留出版图。历史 20 点滤波完整复现与本版独立显示滤波的证据范围在图集说明中各有记录。

## 新增数据的阅读方式

同一章的“native named fields”表保留电子原件行号和独立对位标志。印表的每格在 PDF 和 HTML 中可读；V 表示人工看过底图，A 是原 OCR 与独立图像读取一致；B 是扫描阈值下的空白，S 是另记的跨行标签。问号记尚待判定的来源差别。对应单元格证据 CSV 保留两种读值、所选记录与精确坐标。

SR 章首页附对象决定表，项目与原页相连。标为已确认的是发表对象及开篇位置；已撤回的正文提及单列，图面、图注全文与续页分别采用已有证据。新增印表附各自的原版核对区域和编校说明。

## 本轮影像校读与重绘

原刊 OCR、精校块与逐字段读法分别保留。Site 846 IR 69 页均有按影像校读的正文或题注，指定的图内或表内读数另行登记。SR 第 15、30 章的全文与题注、SP 前言及科学正文、PR 科学与技术报告都有逐行依据。11 个站章另可查逐孔核验的刊载数据。含有上下标的量名使用实际字形和版面层次。全卷 85 个新增图号所用的计量数据、刊印选择与现代假设见 [修订索引](../revision/README.md)。

## 本次全卷导出

76 个分册覆盖 1,922 个主体来源页，PDF 合计 5,629 页。其中 3,594 页为重排与结构化资料，113 页为精校站卡与具名图件，另保留 1,922 个整页见证。1,893 个原图像流引用通过字节核验。

PDF 和 HTML 实际编排 201 项表的具名表示，包含新接入的 92 份 IR 电子表、63 份 IR 印表、7 份 SR 印表。IR 印表的 6,273 个单元格中 957 个待复核；其他状态可在 table_and_object_checks.json 查验。SR 的 809 个已接受项目与 3 个撤回的正文提及分别标明。

source_regions.csv 记录 2,139 个来源定位，产生 1,970 个范围裁片。图面内 54 个量轴区域、11 个整图范围单列。另有印表窗口、图注定位和历史文字证据。rate_plot_lineage.csv 给每站绘图器、图件及输入数表 SHA-256。Site 853 随盘原行 59 的 0.14 在有机碳 MAR 栏，非碳酸盐 MAR 留空。

SR 附读另外逐项列出此前没有具名数据的 177 张印表，含 251 个来源页段。其中 177 张有位置候选，坐标读数覆盖 10,033 条物理行、71,641 个候选表体槽。44 行有人工逐字段读值；另有 22 个符号核过列名与位置，样品归属未定。13 个证据段列于相应 SR 分册末的 29 页附读。附读页置于章末；本版的原页与重绘页位置可在 pages.csv 查得。

PR 综合地层图的 22 页对照图集作为 HTML 附读。已发布数值用于重绘 66 个物性面板，极性、时代、图示岩性、单元与深度轴保留原印图。历史 20 点滤波尚未复原，显示滤波另有编校说明。
