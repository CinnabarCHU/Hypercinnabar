# Leg 138 IR 印表字段与校读

本目录收录第一版 IR 目录中只有题注索引、且未找到原生随盘文件的 **63 张表**，共 **64 个表区**。第 2 章表 5 有一页续表。依据官方站章 PDF 把印本表头对应到有名称的列，再以印行维护文字、刊值、空格和源位置。共 1,516 条物理行，6,273 个单元格位置。

- **907 个单元格人工比对过扫描版**，包括每张表至少一行的可辨值。16 张表的印本数据体逐行全部比对。完整清单见 verification.json。
- **3,377 个单元格**在官方 PDF 文字层和另行运行的光学识别中读数一致。**957 个单元格**仍须对原页判读，具体为两个读法有异、仅一读法、靠近列线或留有未获识别的墨迹。
- **988 个空格**在所设图像墨迹阈值下为空，不能据此推断零值或测量未进行。粒度表有 **44 个位置**共同对应图面上纵排的三枚标签，另存跨度标签。人工核过的一些空格已经计入 907，以上各数互斥。

## 阅读与复核

|文件|作用|
|---|---|
|data/datasets.csv|逐表入口。每行给出 dataset_id、item_id、章、站、印页、PDF 页、源文件哈希、行数、单元数和待校数|
|data/print_rows.csv.gz|每一物理行给出有名称的字段和值的 JSON、表内行序及页内边界。行号跨续页连续|
|data/print_cells.csv.gz|逐单元给出当前读数、两个读法、实际 PDF 文本包框、光学识别包框、单元所在区域和审校状态。所有坐标以 PDF 左上角为原点，单位为 pt|
|data/regions.csv、layouts.psv|每个表区的题注、标题文字层、表头、正文范围和列间边界。源表没有精确电子行的情形可以据此重新裁取|
|data/manual_readings.csv|人工核读记录，以表号、PDF 页、字段和印行中心定位，作为再生成的输入。指定读法和支持依据保存在同一行|
|data/pole_notes.csv|10 张古纬度或古位置表所附旋转极、角速度、范围或相邻区域的核查结果|
|data/spanning_print_labels.csv、editorial_notes.csv|跨行竖排标注及已发现的排字异常、跨孔标签冲突、重复印行、单位和出版差异|
|data/optical_tokens.csv.gz|独立 OCR 字词、置信度和位置。此文件可重跑光学识别生成|

**古位置表。** 10 张表共 131 个年龄行，年龄、印出的纬度及有提供的西经全部对过扫描件。各表沿用其原有坐标约定，如 °S、°N，或南纬记负号。两张只刊古纬度的表未增补经度。Site 853 旋转注写 0.83°/m.y.，前几站常见 0.84°/m.y.。第 19 章表 15 在 Site 854 章中却题作 Site 851，数据库保留原题及所属章。此前已整理的 Site 846 印表在上一级 site846_prior 中。

**原始出版数据的组织。** 年龄校准、古位置、物性均值、换算关系及响应函数属于出版的解释或派生产品。印行可对应连续描述片段、多栏正文或某一组标题。部分船上日志有一个程序描述跨数行，统计量含“±”的印值作为同一栏留存；空位、重复站名、重复值及异常深度字符串保留。该模块不建立物理样品 ID，也不据常识改变刊值。

## 复建

在目录根运行，ir_primary 指含 VOLUME/CHAPTERS 的目录。需要 Python 3、PyMuPDF、NumPy、Pillow 及 Tesseract 5（English）。随附的独立识别缓存可用于跳过第一条命令。检验脚本核对原章 PDF 哈希、题注和表体坐标范围、列名、行到单元的回链、全部 907 个人工读法和 16 张逐行核读表的状态。

```bash
python tools/optical.py /path/to/ir_primary
python tools/build.py /path/to/ir_primary
python tools/verify.py /path/to/ir_primary
```

判读以原印面为最终见证。官方 PDF 文字层和对同一扫描像素的 Tesseract 读法属于同一个出版版本。两种机器读法一致不等于人工精校。图像阈值只用于区分空区与未转录墨迹。物理行和单元位置适合检索与回查，多行表在进一步整合前还应保留一个科学家可审阅的逻辑行分组。

## 地理和古位置

data/leg138_geography.geojson 包含 PR 表 1 中的 42 个实际孔位，以及 IR 各站章中 11 张古位置表的 149 个年龄行，包括此前精校的 Site 846。data/geography_sources.csv 逐表标明刊题、印页、PDF 链接、哈希及坐标约定。GeoJSON 点统一为东经正、北纬正，经度在前；原刊数值和南北纬约定一并保留。

其中 104 个古位置行同时有经纬度且题名与站章一致，适合默认地图。Sites 844 和 845 仅刊古纬度，共 36 行，未给这些行补经度。Site 854 章表 15 的 9 行属于题名冲突，机器接口中 site 为空，chapter_site 为 854，printed_caption_site 为 851。两类记录的 geometry 为空，来源表的实刊数值可通过 properties 读取。孔位按孔保存，古位置按站章出版表保存。

```bash
python tools/geography.py /path/to/ir_primary /path/to/sppr/core
```
