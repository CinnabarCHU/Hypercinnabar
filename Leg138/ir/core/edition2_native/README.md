## 读取与版本

- `datasets.csv`、`dataset_items.csv` 沿用整卷索引格式。每份表的 dataset_id 为 `IRxx.Txx.native.fields`，`data_path` 相对 **ir/core**，例如 `edition2_native/tables/IR09_T13.csv`。`scope=cross-site` 指跨站章节。每表单独列明字段。
- `coverage.csv` 逐表给出源路径及 SHA-256、原始物理行数、数据行数、字段清单、带旗标的行数和布局状态。`original_headings_and_notes.csv` 保留单位及源注释的全文。空字段和零在 CSV 中分别为 `""` 和原 `0` 字串，因表而异的单位可据 `item_id` 从相应源表头查回。
- `tables/` 中的每行给出 `item_id`、`site`、`source_path`、`source_line`（从 1 开始）、`verification_flags` 与 `raw_source_line`。一个数值字段可载有原范围、限值、问号或两个候选年龄。用途要求数值计算时须先明确如何处理这些记号。
- `source_lines.csv.gz` 包含全部源行与其 `line_ending`，Latin-1 一一映射原字节。`review_queue.csv` 有 25 份表共 116 个有说明的行，既收入已核实的版本差异，也记录原表列义有歧义之处。`IR12.T03` 第 6 行的尾部是唯一暂存 `unresolved_source_fragment` 的原表残段。
- `print_witness_notes.csv` 记录定点查验印本的校记。例如 Site 845 表 10 的纸页 229 中列为 **沉积速率、年龄**，随盘表头作 **年龄、速率**，数字顺序相同。Site 853 表 12 纸页 1052 和随盘原表的末个区间均将 0.14 放在有机碳质量累积速率一栏。Site 849 表 4 纸页 762 和电子原表均将孔组写作 844B；Site 850 表 4 随盘遗漏的孔名可在纸页 829 核实为 850B。

## 复建与验证

在同级底本目录 `ir/primary` 和基线目录 `ir/core` 已就绪时，以下命令从航次总目录运行，依赖 Python 3 标准库。

```sh
python ir/core/edition2_native/tools/build.py
python ir/core/edition2_native/tools/print_notes.py
python ir/core/edition2_native/tools/verify.py
```

每次复建从第一版 `table_coverage.csv` 选择其余 92 份原文件。验证器逐字节重组所有 3,252 行并对比源文件哈希，检查全部 2,726 条数据行的原始词元在具名字段及显式残段中出现的次数完全相同。原行字串保留赋值之前的空白及列位置。逐字节核对验证电子见证的完整性，印本的定点校勘范围见校记。后续若更改列义、补孔号或修订年龄，应在可追溯的衍生记录中说明依据。
