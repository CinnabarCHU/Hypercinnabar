# Sources, scope and reproducibility

The reference unit for software parity is a complete output for a named version, parameter set and input. Geological comparisons use the same observations across methods. A published optimum can be a comparison value even when several interpretations of the geology remain plausible.

## Data provenance

All ten previously prepared uninterpolated XY series from the geological benchmark collection are registered by content hash. Preserve the source coordinate, original row order and duplicates. Run `python bench.py dataset dsdp607 607.csv` to export one. On first use, externally hosted sources are fetched by SHA-256 and transformed according to the record definition. Set `CYCLOBENCH_CACHE` to a persistent directory to use the same raw bytes offline. `python bench.py verify --sources` checks all local fixtures and reconstructs every externally defined table. Their roles are prospective. The developing Green River three-well and Terminal-Bench-Science held-out instances retain their separate evaluation protocol. ## Numerical and scientific readouts

- The case comparator checks headers, column order, dimensions, finite values and per-element tolerances. Numerical receipts include the largest absolute error and row for each column. A cached reference scoring itself is a scorer test. The candidate runners compute outputs independently.
- The primary SWA features are the registered FDR and peak criteria. The archive's Lavernock candidate recorded an unavailable FDR curve. An implementation can report a null threshold. The PETM broad and published-protocol runs had full-search maxima at 26.43 and 28.93 cm/kyr respectively; both missed 8–15. These are inherited MATLAB observations, independently preserved alongside new baselines. [Original run receipts](../catalog/historical-results.json)
- All duration/rate deviations use the stated units. LR04 gaps are reconstruction tests with the actual withheld measurements. Clock errors are unweighted over supplied query rows. The CIP interval-duration diagnostic uses 269.85–343.95 m. The ODP 846 grid is depth-weighted to grid accuracy. The C/T comparison reports interval width and endpoint deviations when the method supplies uncertainty.
- The portable baseline uses linear interpolation, a rectangular-window periodogram and a few explicitly simple comparators. Rate scans average log spectral power at the template frequencies, Bridge Creek uses a Gaussian weighted linear fit to the four ages, and the synthetic detection panel uses AR(1) prewhitening and a two-frequency Bonferroni test. The native R Site 926B example runs modern TimeOpt after 0.1 m interpolation and an explicitly chosen LOESS span of one nominal cutoff wavelength divided by the record length. Scores and candidate versions are kept in individual receipts.
- Cite each record's depositors and article when reusing data. The root license covers the repository's original benchmark code. External data, imported tests, and archived upstream products retain their source attribution and applicable terms.
